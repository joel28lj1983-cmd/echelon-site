# echelonadvisorygroup.org

Static marketing site for Echelon Advisory Group LLC, a CMMC readiness advisory
practice. Plain HTML and CSS with one small client-side self-check. No framework,
no build step, no tracking, and no external requests.

## Structure
- index.html, services.html, region.html, about.html, contact.html - the pages
- readiness/index.html - a self-contained CMMC Level 1 self-check that runs in the
  browser and stores and sends nothing
- style.css - shared styles
- CNAME - custom domain for GitHub Pages
- favicon.svg, robots.txt, .nojekyll

## Deploy (GitHub Pages)
Publish this folder to the repository root and enable GitHub Pages on the default
branch. The CNAME file points the site at echelonadvisorygroup.org.
